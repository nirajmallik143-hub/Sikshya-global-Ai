## 🌟 Executive Summary

**Sikshya Global AI** represents a paradigm shift in digital pedagogy. Built as a high-performance, ultra-lightweight Progressive Web App (PWA), it integrates cutting-edge generative AI directly into the browser. By combining real-time multi-modal processing (voice, vision, and document analysis) with localized academic frameworks (such as the Nepal CDC Grades 1-12 & SEE curriculum), Sikshya delivers personalized, barrier-free tutoring to students anywhere on Earth.

## 🚀 Local Setup & Termux Deployment Guide

If you are running, testing, or pushing updates to this repository locally via an Android Termux environment, follow this secure pipeline:

### 1. Clone & Initialize Repository
```bash
git clone https://github.com/nirajmallik143-hub/Sikshya-global-AI.git
cd Sikshya-global-AI
```

### 2. Configure Your API Key
Open `index.html` in your text editor (e.g., `nano index.html`) and paste your authorized Google Gemini API key into the secure configuration constant:
```javascript
const GEMINI_API_KEY = "YOUR_GEMINI_API_KEY_HERE";
```

### 3. Local Development Preview
Launch a lightweight local Python server to test your PWA interface in any browser:
```bash
python3 -m http.server 8000
```
*(Navigate to `http://localhost:8000` in your browser)*

### 4. Push Updates to Production (GitHub Pages)
```bash
# Pull remote modifications with unrelated histories merged
git pull origin main --allow-unrelated-histories

# Stage and commit your files
git add .
git commit -m "Deploy 7G-Quantum feature update"

# Push securely to origin main
git push -u origin main
```
